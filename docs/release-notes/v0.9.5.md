# LAVRay 0.9.5 для Android

Третий выпуск. Новое: набор маршрутов LAV Preset RU Linux по умолчанию и два списка приложений, «Всегда через VPN» и «Всегда напрямую», которые важнее любых правил маршрутов. Ядро на Go теперь живёт в этом репозитории и развивается только для Android; версия ядра равна версии приложения, 0.9.5.

**Проверено на эмуляторе x86_64 с Android 16. На реальном телефоне выпуск проверяет владелец; результаты этой проверки в заметки не вошли.** Что проверено на эмуляторе, перечислено в [docs/MEASUREMENTS.md](https://github.com/anatolijlaptev1991-ctrl/lavray-android/blob/main/docs/MEASUREMENTS.md), раздел 12.

## Что нового

- **LAV Preset RU Linux** — набор по умолчанию: тот же LAV Preset RU (российские сайты и игры напрямую, остальное через сервер, раздельный DNS), но без правил для программ Windows, которые на телефоне ничего не выбирали. Маршруты от этого не меняются. При обновлении набор переключается сам, только если вы раньше не выбирали набор вручную; выбор DNS, сделанный для LAV Preset RU, переходит к нему. LAV Preset RU остаётся в списке.
- **«Всегда через VPN»** («Настройки» → «Туннель» или экран «Правила»): весь интернет-трафик и DNS-запросы выбранных приложений идут через сервер, даже к российским сайтам и даже если приложение не выбрано в «Приложениях в туннеле». Устройства домашней сети (роутер, принтер) остаются доступны напрямую.
- **«Всегда напрямую»**: выбранные приложения работают как без VPN, их трафик никогда не идёт через сервер. Обычно они просто исключаются из туннеля. Если в Android включено «Блокировать подключения без VPN», они остаются в туннеле, а ядро отправляет их трафик напрямую, мимо сервера: иначе Android оставил бы их без сети.
- Одно приложение может быть только в одном списке: в другом списке оно подписано «В списке …» и не отмечается. Изменение списков, как и выбора приложений, применяется после «Переподключить», приложение это предлагает.
- **Ядро в этом репозитории.** Раньше ядро подключалось из общего репозитория настольной LAVRay. Теперь оно в `core/`, лишние для телефона части убраны, а доработки под Android внесены прямо в код. Для пользователя это ничего не меняет.

## Производительность

Пока список «Всегда через VPN» пуст, приложение на него ничего не тратит. Если в нём есть приложения, ядро на каждое новое соединение один раз спрашивает систему, чьё оно: на эмуляторе это добавило 1–3 мс к открытию соединения. На скорость уже открытого соединения это не влияет. Список «Всегда напрямую» без блокировки ничего не стоит: такие приложения в туннель не заходят.

Размеры файлов этого выпуска — на странице выпуска, в списке файлов.

## Какой файл выбрать

| Файл | Для чего |
|---|---|
| `LAVRay-0.9.5-arm64-v8a.apk` | почти все современные телефоны и планшеты; если сомневаетесь, берите его |
| `LAVRay-0.9.5-armeabi-v7a.apk` | старые 32-битные устройства |
| `LAVRay-0.9.5-x86_64.apk` | эмуляторы и Chromebook |
| `SHA256SUMS` | контрольные суммы |

Один APK содержит ядро только для своей архитектуры, универсального файла нет.

## Как обновиться

Установите APK поверх 0.9.4 (или 0.9.3): подпись та же, данные (серверы, подписки, настройки) сохранятся. Номер версии APK — 905 × 10 + 1, 2 или 3 для `armeabi-v7a`, `arm64-v8a`, `x86_64`. Если при обновлении с 0.9.4 туннель был включён, он вернётся сам через несколько секунд. Приложение само новых версий не ищет.

## Как проверить файл

Скачайте нужный APK и `SHA256SUMS` в одну папку.

Linux и macOS:

```bash
sha256sum -c --ignore-missing SHA256SUMS      # на macOS: shasum -a 256 -c --ignore-missing SHA256SUMS
```

Windows (PowerShell или командная строка):

```powershell
Get-FileHash .\LAVRay-0.9.5-arm64-v8a.apk -Algorithm SHA256
```

```bat
certutil -hashfile LAVRay-0.9.5-arm64-v8a.apk SHA256
```

Результат должен совпасть со строкой этого файла в `SHA256SUMS`.

Сертификат `CN=LAVRay, O=LAVRay`, отпечаток SHA-256: `fe058a98b9abb7ba8c853c0ae39c893aeeffa6892eb5a243e22718c2ac58fbb3`. Сверка: `apksigner verify --print-certs <файл>.apk`. Сборки, подписанные другим ключом (в том числе локальные отладочные), поверх не встанут: их нужно удалить.

## Известные ограничения

- На реальном телефоне выпуск пока не проверен, ядро не запускалось на arm64 и armeabi-v7a.
- На Android 9 и старше система не сообщает, чьё соединение. Там «Всегда через VPN» гарантирует только, что приложение в туннеле, а его трафик идёт по правилам набора; экран выбора об этом предупреждает.
- Android сообщает приложению о «Блокировать подключения без VPN», только когда VPN уже поднят. Поэтому при запуске под блокировкой первый туннель строится без неё, а после «Подключено» приложение один раз пересобирает его: на эмуляторе это заняло от 0,6 до 7 секунд. Всё это время приложения из «Всегда напрямую» без сети, мимо VPN ничего не уходит. Если включить блокировку при уже поднятом VPN, нажмите «Переподключить».
- Если в режиме «Только выбранные» все выбранные приложения стоят в «Всегда напрямую», туннелировать нечего: подключение не состоится с ошибкой «Ни одного из выбранных приложений нет на телефоне» (формулировка общая для обоих случаев).
- Закрытым при гибели приложения остаётся только системный Always-on VPN с «Блокировать подключения без VPN». Удержание в самом приложении длится не дольше 30 секунд и работает только при пересборке туннеля.
- Принудительная остановка приложения в настройках Android отключает туннель, и он не возвращается, пока вы сами не откроете приложение.
- Приложение, установленное или переустановленное при включённом туннеле, начинает подчиняться спискам только после «Переподключить»: сам Android их при установке не пересчитывает.
- Автоподключение после перезагрузки работает после первой разблокировки телефона. Оболочки Xiaomi, Huawei, Samsung, Oppo/Realme/OnePlus и Vivo могут блокировать автозапуск, тогда LAVRay нужно внести в исключения вручную.
- Если режим «IPv6 через туннель» выключен, IPv6 приложений в туннеле блокируется (напрямую не уходит).
- Редко (один раз примерно на 120 перезапусков ядра на эмуляторе) после смены сервера или перезапуска ядра трафик через туннель не идёт до следующего перезапуска; наружу при этом ничего не уходит. Помогает «Переподключить». Причина не найдена.
- Tor убран из сборки; транспорт XHTTP импортируется, но ядром не поддерживается; самообновления нет.
- Часть функций настольной версии не перенесена: [docs/NOT-PORTED.md](https://github.com/anatolijlaptev1991-ctrl/lavray-android/blob/main/docs/NOT-PORTED.md).
