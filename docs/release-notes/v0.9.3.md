# LAVRay 0.9.3 для Android

Первый выпуск LAVRay для Android: нативное приложение на Kotlin и Jetpack Compose поверх ядра LAVRay 0.9.3 (то же ядро, что в [LAVRay для Windows](https://github.com/anatolijlaptev1991-ctrl/lavray-windows)). Названия, наборы маршрутов, экраны и цвета те же. Версия приложения совпадает с версией ядра.

**Проверено только на эмуляторе x86_64 с Android 16. На реальном телефоне выпуск ещё не проверялся.** Если найдёте ошибку, см. «Сообщить об ошибке» ниже.

## Что внутри

- Серверы и группы, подписки с обновлением по расписанию и откатом.
- Импорт: ссылка, буфер обмена, QR-код (камера и картинка), файл. Ссылки серверов можно открыть в LAVRay из другого приложения или отправить через «Поделиться».
- Проверка задержки и URL-тест.
- Наборы маршрутов: «Глобальный», «Всё через прокси», «Всё напрямую», **LAV Preset RU** (ревизия 3, включён по умолчанию) и LAV Preset CN. Свои наборы, импорт и экспорт, проверка маршрута.
- DNS, соединения, журнал, статистика, экран «Почему не работает?».
- Приложения в туннеле: все, только выбранные или все, кроме выбранных.
- Автоподключение после перезагрузки к последнему серверу и поддержка системного Always-on VPN.
- Резервная копия в зашифрованный файл (выбор файла через систему), восстановление из неё.
- Пять языков интерфейса: русский, English, 中文, Español, Deutsch. Светлая и тёмная темы, акценты.
- Туннель всегда на gVisor, MTU 9000 по умолчанию; выбора стека в настройках нет.
- Раздел «Обновления» только открывает страницу выпусков: приложение не обращается в сеть за новыми версиями и само не обновляется.

Идентификатор приложения `io.github.anatolijlaptev1991_ctrl.lavray`, Android 8.0 или новее (minSdk 26), targetSdk 36.

## Замеры

Только на эмуляторе x86_64 с Android 16 (2 vCPU), не на телефоне. Подробности и методика — [docs/MEASUREMENTS.md](https://github.com/anatolijlaptev1991-ctrl/lavray-android/blob/main/docs/MEASUREMENTS.md).

- Размер APK: 20,65 МБ (arm64-v8a), 21,24 МБ (armeabi-v7a), 21,97 МБ (x86_64).
- Холодный старт интерфейса: медиана около 1,26 с.
- Память процесса `:vpn` в простое: около 67 МБ PSS; wakelock, будильников и заданий нет.
- Нажатие «Подключить» до первого ответа через туннель: медиана 844 мс с локальным тестовым сервером.

Не измерены расход батареи, скорость на реальном телефоне и запуск на arm64 и armeabi-v7a.

## Какой файл выбрать

| Файл | Для чего |
|---|---|
| `LAVRay-0.9.3-arm64-v8a.apk` | почти все современные телефоны и планшеты; если сомневаетесь, берите его |
| `LAVRay-0.9.3-armeabi-v7a.apk` | старые 32-битные устройства |
| `LAVRay-0.9.3-x86_64.apk` | эмуляторы и Chromebook |
| `SHA256SUMS` | контрольные суммы |

Один APK содержит ядро только для своей архитектуры, универсального файла нет.

## Как проверить файл

Скачайте нужный APK и `SHA256SUMS` в одну папку.

Linux и macOS:

```bash
sha256sum -c --ignore-missing SHA256SUMS      # на macOS: shasum -a 256 -c --ignore-missing SHA256SUMS
```

Windows (PowerShell или командная строка):

```powershell
Get-FileHash .\LAVRay-0.9.3-arm64-v8a.apk -Algorithm SHA256
```

```bat
certutil -hashfile LAVRay-0.9.3-arm64-v8a.apk SHA256
```

Результат должен совпасть со строкой этого файла в `SHA256SUMS`.

## Подпись

Выпуск подписан релизным ключом, который описан в [docs/SIGNING.md](https://github.com/anatolijlaptev1991-ctrl/lavray-android/blob/main/docs/SIGNING.md). Обновление Android ставит поверх только APK с тем же именем пакета и той же подписью. Сборки, подписанные другим ключом (в том числе локальные отладочные), поверх не встанут: их нужно удалить.

## Установка и обновление

Разрешите установку из выбранного источника, откройте APK и подтвердите. При первом подключении Android 13 и новее спросит разрешение на уведомления, затем покажет окно согласия на VPN. Новые версии приложение не ищет само: скачайте APK со страницы выпусков и поставьте поверх, данные сохранятся.

Проверка на телефоне: [docs/PHONE-CHECKLIST.md](https://github.com/anatolijlaptev1991-ctrl/lavray-android/blob/main/docs/PHONE-CHECKLIST.md).

## Известные ограничения

- Не проверено на реальном телефоне, только на эмуляторе.
- Автоподключение после перезагрузки работает после первой разблокировки телефона; принудительно остановленное приложение не получает сигнал загрузки до первого ручного запуска. Оболочки Xiaomi, Huawei, Samsung, Oppo/Realme/OnePlus и Vivo могут блокировать автозапуск, тогда LAVRay нужно внести в исключения вручную. Самый надёжный способ — системный Always-on VPN.
- Транспорт XHTTP: ссылки импортируются, но ядро его пока не поддерживает.
- Нет самообновления и автоматической проверки обновлений.
- Часть функций настольной версии не перенесена (редактор сервера, «Полный тест», мастер первого запуска, системный прокси, локальный прокси, веб-панель и другие). Полный список с причинами — [docs/NOT-PORTED.md](https://github.com/anatolijlaptev1991-ctrl/lavray-android/blob/main/docs/NOT-PORTED.md).
- Проверка DNS-утечки и «прямого IPv6» на телефоне не измеряется.

## Сообщить об ошибке
