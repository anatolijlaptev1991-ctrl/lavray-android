# Что не перенесено с рабочего стола и почему

Список сверен с экранами и компонентами `third_party/lavray/ui/src` (v0.9.3). Одна строка на пункт: что, причина, чем заменено.

## Системные возможности

- Системный прокси и его настройки (`set.sysproxy`, `connect.kill_switch_proxy`): у Android нет общесистемного прокси, трафик берёт `VpnService`.
- Локальный прокси HTTP+SOCKS, порт, логин и пароль, доступ из локальной сети (`inbound.*`, `set.lan`): слушателя на телефоне нет намеренно, чтобы другие приложения не находили порт; проверка «порт свободен» скрыта.
- Глобальные и внутриоконные горячие клавиши (`hotkeys.*`): на телефоне нет клавиатурных сочетаний уровня системы.
- Значок в трее, «свернуть в трей», «запуск свёрнутым», «подтверждать выход»: у Android нет трея, фоновую работу показывает уведомление службы.
- Автозапуск при входе в систему (`set.autostart`, планировщик): заменён настройкой «Подключаться при запуске телефона» и системным Always-on.
- Режим TUN от имени администратора и помощник повышения прав (`TunDialog`, `TunAdminNotice`): права на туннель даёт согласие VPN, а не повышение прав.
- Kill-switch через брандмауэр (`tun.kill_switch`, `tun.strict_route`): заменён системным Always-on с блокировкой соединений без VPN, LAVRay его не видит и не меняет.
- Исключения по процессам (`tun.bypass_process`, правила `process_name`): на телефоне процессов нет, вместо них режим «по приложениям» с выбором пакетов.
- Режим белого списка TUN (`tun.whitelist`): заменён режимом «только выбранные» в выборе приложений.
- Имя интерфейса TUN, скрытие консоли (`tun.interface_name`, `tun.hide_console`): интерфейс создаёт система, консоли нет.
- Внешние ядра и Clash API (`enable_external_cores`, `core.clash_api.*`): внешних исполняемых файлов и локальных слушателей на Android нет.

## Обновления

- Самообновление ядра и приложения, каналы stable/beta, откат, установка из файла, проверка подписи (`UpdateService`, экран «Обновления»): устанавливает приложения система; в приложении только страница выпусков и ручная установка.
- Автоматическая проверка обновлений (`update.auto_check`): приложение не обращается в сеть без действия владельца.
- Отдельное обновление наборов маршрутов и geo-данных (`upd.comp.*`): оно входит в отключённый механизм обновления, поэтому данные меняются только с новой версией приложения.

## Другие устройства и интеграции

- Миграция из NekoBox (`MigrationService`, «Импорт из NekoBox»): на телефоне нет каталога настольного NekoBox.
- Доступ для ИИ-агентов и MCP (`agent.mode`, `AgentsSettings`): агенты работают на компьютере, MCP-сервер в сборку для телефона не входит.
- Веб-панель, вход и сессии (`WebSessionService`, `web.*`): панели на телефоне нет.
- Шлюз и устройства сети, OpenWrt (`GatewayService`, `router.*`): телефон не раздаёт туннель другим устройствам.

## Мелочи экранов

- Показ действующего конфига ядра в «Проверках» (`RuntimeConfigCard`): конфиг содержит адреса серверов и нужен для отладки на компьютере; не перенесено.
- «Создать правило» из строки соединения (`conns.ruleDirect`, `conns.ruleProxy`): правки наборов маршрутов принадлежат экрану «Маршруты».
- Проверка DNS-утечки (`leak.dns.run`): у ядра нет тестового домена, который показал бы резолвер, поэтому замер не выполняется и в отчёте назван «не измерено».
- Проверка «прямой IPv6»: сам LAVRay исключён из туннеля, и его собственный IPv6 ничего не доказывает; в отчёте «не измерено».
- Проверка доступности (a11y-панель `a11y.*`) и прототипные подсказки: инструмент разработки, на телефоне есть TalkBack и средства Android.
- Сохранение журнала файлом (`log.export`): заменено кнопками «Копировать» и «Поделиться» (системное меню отправки).
- Системное уведомление о перезапуске ядра (`RestartBanner`): ядро перечитывает настройки при следующем подключении, об этом сказано в самих настройках.
