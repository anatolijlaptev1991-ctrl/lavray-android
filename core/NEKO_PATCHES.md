# NEKO_PATCHES.md — реестр neko-патчей над sing-box

Форк `anatolijlaptev1991-ctrl/sing-box` (пин `35f3fd0` = `628a9ed` + патч P1, база 1.14.1) содержит neko-слой —
изменения поверх upstream sing-box, через которые Go-ядро nekoray управляет библиотекой.
Этот реестр — заготовка: при обновлении пина каждый пункт проверяется и переносится (или
осознанно отбрасывается) — см. гейт обновления в [UPDATE-SYSTEM.md в lavray 0.9.3](https://github.com/anatolijlaptev1991-ctrl/lavray/blob/v0.9.3/docs/UPDATE-SYSTEM.md).

> Источник анализа: [AUDIT.md в lavray 0.9.3](https://github.com/anatolijlaptev1991-ctrl/lavray/blob/v0.9.3/docs/AUDIT.md) (аудит связки ядро ↔ UI). Заполняется по фактическому
> diff `628a9ed` против upstream при старте Этапа 3.

## Патчи поверх пина (не neko-слой)

Исправления upstream-багов, которые форк получил раньше, чем его пин дойдёт до версии upstream с исправлением.

| # | Файлы форка | Суть | Upstream-эквивалент | Статус |
|---|---|---|---|---|
| P1 | `transport/v2rayhttpupgrade/server.go`, `client.go` (+ `transport_test.go`) | Inbound httpupgrade терял байты, уже лежавшие в read-буфере net/http после `Hijack()` (первый байт сразу после 101; в e2e это `unknown version: 184` на `vless_httpupgrade`): буфер `*bufio.ReadWriter` не вычитывался. Клиент читал буфер через `buffer.Len()` (=0) вместо `FreeLen()` и тоже терял байты, пришедшие вместе с 101. Влияет только на серверную (inbound) сторону; LAVRay как клиент не затронут. | SagerNet/sing-box `52f9bad034d2` «Fix protocol input validation» (часть про httpupgrade) | перенесён в форк, [anatolijlaptev1991-ctrl/sing-box#1](https://github.com/anatolijlaptev1991-ctrl/sing-box/pull/1); при переходе на upstream с этим коммитом — заменяется upstream-версией |

## Правила ведения реестра

1. Один патч — одна строка (или один раздел, если большой): файлы, суть, зачем, upstream-эквивалент.
2. При обновлении пина sing-box: каждый пункт получает вердикт `перенесён / заменён upstream-фичей / удалён` + ссылку на коммит.
3. Реестр — обязательное приложение к PR обновления ядра; без него гейт не проходит.
