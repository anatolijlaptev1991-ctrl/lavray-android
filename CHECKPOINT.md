## Экран «Подключение»: паритет с десктопом (2026-11-10)
- `ExitProbe` (env.exit): один проход разовых вызовов (CheckLeaks, GetDns, TCP-замер активного сервера) после подъёма туннеля, только пока экран виден; кэш на соединение (ключ «сервер:время старта»), ручное обновление, без опроса; при остановке экрана проход отменяется и состояние возвращается. Страна берётся из `Profile.geo` сервера (как на десктопе), не из замера выхода.
- Быстрые действия: проверить серверы, добавить сервер, обновить подписки (`env.subscriptions`, модель создаётся при первом нажатии).
- Разбор import-предпросмотра ss:// — `SsLinkCheck` повторяет правила `parseSS` ядра (base64 с «=», пара «метод:пароль», список шифров). Если правила ядра изменятся, сверить.
- Не сделано: подтверждение для подписок на частные адреса (на десктопе его нет: `allow_private_urls` только настройкой ядра `sub.allow_private_urls`, без интерфейса).
- На эмуляторе не видно состояние «утечек нет»: тестовый сервер на том же ПК выходит в сеть тем же адресом, что и прямой замер (проверено только тестом).
